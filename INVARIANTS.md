# Invariants

1. **No Justification Is Not Clearance.** Expiry removes standing. It does not
   establish recovery, information quality, or publisher approval.
2. **Historical Authorship Is Not Current Ownership.** A successful past mute
   request and an identical current mute do not authorize automatic release.
3. **Unknown May Change the Winner.** If missing admissible evidence could permit
   a higher-precedence disposition, the result is indeterminate.
4. **Rule Order Has No Authority.** Conclusive allow defeats quarantine;
   declaration order does not change the result or policy hash.
5. **Exemption Is a Jurisdiction Boundary.** It suppresses automated effects,
   without rewriting the underlying policy conclusion.
6. **Keep-Muted Is an Enforcement Override.** It prevents release, creates no
   mute, and makes no observation true.
7. **Refetch Does Not Renew Standing.** Evidence identity excludes retrieval time.
   Maximum age is measured from the publisher's observation time.
8. **Preview Cannot Enforce.** Fixtures cannot authenticate, authorize writes, or
   share a state database with live evidence.
9. **Existing State Is Not Adopted.** Full, scoped, or list-derived pre-existing
   mutes are preserved without attribution or expansion.
10. **Ambiguous Writes Remain Ambiguous.** Pending/uncertain actions are journaled
    and suspended, never silently replayed or assigned ownership.

These are executable behavior contracts in the offline test suite. See
`test_no_justification_is_not_clearance` and
`test_historical_authorship_is_not_current_ownership` for the named regressions.
