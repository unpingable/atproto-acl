# Non-goals for V0

- Publishing a canonical roster or implementing native moderation-list writes.
- Automatic release of private mutes.
- Blocking, reporting, or publishing labels.
- Measuring raw posting activity or inventing numeric counts from categories.
- Inferring intent, mental state, ideology, toxicity, or information quality.
- Claiming every feed will remove every matched account.
- Claiming complete historical label coverage from an exhausted endpoint.
- Hosted authentication, multi-user web operation, or a custom-feed server.

The library boundaries support future adapters and UI development without
changing the evaluator's meaning.
